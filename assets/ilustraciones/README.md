# Ilustraciones

Set de línea fina (trazo de 1,6 en lienzo de 64 × 64), sin relleno, en el estilo de la mariposa del logo.

- `*-morado.svg` — trazo `morado-alma` (#8D4388), para fondos `marfil` y `rosa-niebla`.
- `*-blanco.svg` — trazo `blanco`, para fondos `morado-alma`, `morado-profundo` y fotos oscuras.

Temas: pie (reflexología), oreja (auriculoterapia), gota y frasco (aceites), lavanda (aromas), hoja (calma), manos (masajes y cuidado), vela (pausa y oración), destello (luz), halo (luz de Dios). Reglas de uso en la sección Ilustraciones.
